Biblioteca UNIR: PWA lista para Netlify. El catálogo usa config.js y Apps Script ya configurados. Las portadas se solicitan a Google Drive como miniaturas del PDF; si Drive no ofrece miniatura pública, se muestra cubierta alternativa. Los PDF deben ser accesibles para lectores. Relax Carmelita es un panel flotante y los dos recursos ApS se abren aparte. Para publicar, sube el ZIP a Netlify.
